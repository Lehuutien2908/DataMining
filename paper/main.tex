\begin{abstract}
Heart disease remains one of the leading causes of mortality worldwide, motivating the development of accurate and reliable machine learning models for early detection. This paper presents an experimental pipeline for binary heart disease classification based on a public Kaggle dataset. Five predictive models are compared, including a support vector machine with RBF kernel, Random Forest, XGBoost, and TabNet.
\end{abstract}

\begin{IEEEkeywords}
Heart disease prediction, machine learning, feature selection, feature importance, TabNet, Optuna, ROC-AUC
\end{IEEEkeywords}

\section{Introduction}
Cardiovascular diseases are major global health concern. Early detection using clinical and demographic attributes can significantly improve patient outcomes. Machine learning (ML) and deep learning (DL) methods have been increasingly adopted for structured clinical datasets.

This work emphasizes systematic model comparison across classical ML and deep tabular DL, and feature influence re-assessment to better understand which attributes drive predictions and how stable these findings are across methods.

\section{Related Work}
Random Forests and SVMs are widely used in medical classification due to robust generalization, while gradient boosting methods such as XGBoost often achieve strong performance on tabular data. For deep tabular modeling, TabNet introduces an attentive mechanism that can offer competitive performance with interpretability. Hyperparameter optimization frameworks such as Optuna facilitate efficient tuning. ROC-AUC is commonly used for binary medical classification due to its threshold-independent property.

\subsection{Outlier Removal with IQR (Train-Fit Bounds, Apply to Both)}
Outlier bounds are computed \emph{only on the training set} for continuous features:
\[
\{\texttt{age},\texttt{trestbps},\texttt{chol},\texttt{thalach},\texttt{oldpeak}\}.
\]
For each feature, the IQR bounds are:
\[
\text{lower}=Q1-1.5\cdot IQR,\qquad \text{upper}=Q3+1.5\cdot IQR.
\]
Using these bounds (estimated from training), the code then removes rows in both \texttt{train\_df} and \texttt{test\_df} that fall outside the bounds. The numbers of removed rows and the bounds per feature are printed during execution and should be reported from logs.

\section{Methodology}

\subsection{RF Feature Ranking}
A Random Forest is trained on the cleaned training set to compute Gini (MDI) feature importances. The resulting importance vector is sorted in descending order to form a ranked feature list.

\subsection{Feature Selection}
Given the ranked feature list, the code evaluates top-$k$ feature subsets for
$k = 1, \dots, d$, where $d$ denotes the total number of available features.
For each value of $k$, a Random Forest classifier is trained and evaluated
using 5-fold stratified cross-validation on the training set, with ROC-AUC
used as the performance metric.

The resulting sweep produces a table containing the number of selected features
($k$), the mean ROC-AUC across folds (\texttt{mean\_auc}), the corresponding
standard deviation (\texttt{std\_auc}), and the average model fit time.
Let $\mu_{\max}$ denote the maximum mean ROC-AUC observed across all values of $k$,
and let $\sigma_{\max}$ be the standard deviation associated with that optimum.

To avoid selecting an overly complex feature subset, the final selection follows
the 1-standard-deviation (1$\sigma$) rule, defined as
\[
\text{threshold} = \mu_{\max} - \sigma_{\max}.
\]
The selected feature subset corresponds to the \emph{smallest} value of $k$
whose mean ROC-AUC satisfies $\mu_k \ge \text{threshold}$.
This criterion favors simpler models with statistically comparable performance,
thereby improving robustness and reducing the risk of overfitting.

\subsection{Feature Scaling}
After the feature subset is selected,
feature scaling is applied to ensure comparable feature ranges for
distance-based and gradient-based models.
A \texttt{StandardScaler} is fitted to the selected features of the training
set and subsequently applied to both training and test data.
\[
X_{\text{train}}^{(s)} = \text{Scaler}(X_{\text{train}}^{\text{sel}}), \quad
X_{\text{test}}^{(s)} = \text{Scaler}(X_{\text{test}}^{\text{sel}}),
\]
where the scaler parameters are estimated exclusively from the training set
to prevent information leakage.


\subsection{Evaluation Metrics}
The evaluation includes accuracy, precision, recall (sensitivity), F1-score,
specificity, negative predictive value (NPV), false positive rate (FPR),
false negative rate (FNR), balanced accuracy, and the area under the ROC curve
(ROC-AUC), providing a comprehensive assessment of classification performance,
particularly under potential class imbalance.



\section{Models}

Five models are evaluated:
\begin{itemize}
\item \textbf{SVM (RBF)}: SVC with RBF kernel, probability=True for ROC-AUC, and class\_weight='balanced'.
\item \textbf{Random Forest}: Example 100 trees, max depth 5.
\item \textbf{XGBoost}: Example 100 trees, learning rate 0.05, max depth 5 (tune as needed).
\item \textbf{TabNet + Optuna}: Hyperparameters optimized using Optuna, objective = cross-validated ROC-AUC.
\end{itemize}


\subsection{SVM}
The support vector machine (SVM) classifier employs a radial basis function
(RBF) kernel with probability estimation enabled (\texttt{probability=True}).
To account for potential class imbalance, \texttt{class\_weight=balanced} is
used. Hyperparameters are optimized via \texttt{GridSearchCV} on the scaled
training data using 5-fold stratified cross-validation with
\texttt{scoring='roc\_auc'}.

$\gamma$ is summarized in Table~\ref{tab:svm_grid}. The optimal configuration
is selected based on the highest mean ROC-AUC across cross-validation folds
and reported from the run log (\texttt{svm\_grid.best\_params\_}).

\section{Discussion}
The pipeline follows a clear separation between train and test: the split is performed before preprocessing , and IQR bounds for continuous variables are estimated on the training set and applied consistently thereafter. Feature selection is performed on the training set using cross-validated ROC-AUC across top-$k$ subsets derived from RF Gini ranking, which reduces the risk of direct test-set selection bias.



\section{Conclusion and Future Work}
This paper presents a heart disease prediction pipeline with train-fit outlier bounds, RF-based top-$k$ feature selection using cross-validated AUC on training data, and a comparison of SVM, XGBoost, Random Forest, and TabNet (Optuna-tuned). Future work includes stricter evaluation protocols (e.g., validation-based early stopping for TabNet), calibration analysis, and external cohort validation.
